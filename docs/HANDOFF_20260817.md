## 3. 关键机制备忘 (踩过的坑)

1. **ACL 陷阱**: overlay/pin 窗口不在 `capabilities/default.json` (`windows:["main"]`)。JS 端插件调用 (dialog 等) 被静默拒 → 一律走 **Rust 侧自定义命令** (不受 ACL 管)。
2. **CJK IME 吃键**: 字母/标点 keydown 的 `e.key==="Process"` → 一律用 **`e.code`** (KeyW/KeyR/Comma/Period)。
3. **平台分歧警告**: Linux 说"多余的 mut/未用 import"可能 Windows 是必需 (cfg 块)。push 前双 target 本机检查:
   ```
   cd src-tauri && PKG_CONFIG_PATH=/tmp/fakepc cargo check --all-targets
   PKG_CONFIG_PATH=/tmp/fakepc cargo check --all-targets --target x86_64-pc-windows-gnu
   ```
   (/tmp/fakepc 伪造 .pc 骗过 GTK 探测;check 不链接 → 假库无碍。cargo test 仍需真库→留 CI)
4. **版本规则**: 十进制版本,补丁位 0-9,逢 10 进位 (0.4.9→0.5.0);已发 tag 不回改。
5. **发版流程**: dev 开发 → 双 target 本机过 → push → CI 三平台绿 → `git push origin dev:main` (ff) → `git tag -a vX.Y.Z <sha>` → push tag → release.yml。无 gh CLI:API 匿名查 run 状态;日志要鉴权→让用户贴。
6. **图层模型**: 标注存 overlay 坐标 (锚定冻结帧,选区移动不糊);drawObjects 单渲染器服务活画布(裁剪到选区)与确认时全物理分辨率合成。
7. **状态机**: UNCONFIRMED(十字/任意重画) → ✓ CONFIRMED(箭头/移动) → 动作(⬆/📋/💾/📌/Ctrl+C)关闭。
