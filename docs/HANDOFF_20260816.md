## 3. 关键实测结论 (写文档/推理时遵守: 现象≠根因)

1. **Orca 拒绝一切合成输入** (Direct+admin 也不行);VSCode 收 Enigo Unicode (admin 下);普通终端两者都收。Auto 模式已按此表自动分流。
2. **Direct 无送达确认** → Enigo 永远 Ok → 靠 `fallback_to_copy` 的剪贴板兜底 (P0 已修)。
3. **F8 vs 直接 Ctrl+V 的语义** (用户 08-16 问透了的): Alt+X 后图片在剪贴板,直接 Ctrl+V 贴的是**图片本体** (Orca 收,走 /tmp/orca-paste-*.png) —— "给 AI 看图"这条路**不需要 F8**。F8 的价值=产出**远程路径** (纯 SSH/tmux 终端贴不进图片时唯一解、可复用引用)。产品提示语可再向用户讲清双路 (已记入讨论,未立项)。
4. **微信截图→剪贴板→Orca 贴图** 平行通道也通。
5. WinSCP (用户叫它 xftp 😄) 双栏验证: 本地压缩件与远程 /tmp/img2cli/ 一一对应,上传链路健康。
