## 1. What Works (Verified by User)

```
Alt+X/Z  Screenshot (region select + confirm, Snipaste-style, no white flash)
   ↓
F8       Upload to remote SSH server (91_mengzijun) + path on clipboard
   ↓
Direct mode (admin) auto-types path into VSCode Claude Code
   OR  Copy mode + manual Ctrl+V
   ↓
[Image #N] → AI sees the screenshot ✅
```

**Key finding**: In VSCode (Chromium/Electron):
- `[direct]` mode (Enigo Unicode char input) **WORKS** as admin — Chromium accepts Unicode char input.
- `[auto]`/`[swap]`/`[paste_keep]` (SendInput virtual-key Ctrl+V) **FAIL** — Chromium rejects synthetic virtual-key shortcuts (`inserted=0`).
- `[copy]` mode + manual Ctrl+V **always works**.

**Best config for VSCode Remote / Claude Code**:
- Output Format → **Raw Path**
- Wrap in Single Quotes → **OFF**
- Injection Mode → **Direct** (as admin) or **Copy Only** (non-admin)
- **Restart as Administrator** (tray menu) for Direct mode to bypass UIPI

## 5. Critical Technical Decisions

### 5.1 Alt+Z is capture-only (v0.3.7)
Alt+Z puts the image in the clipboard and **stops**. It does NOT upload or inject. This decouples screenshot from upload (the screenshot subject and AI CLI are rarely on-screen simultaneously on a single monitor).

### 5.2 SendInput vs Enigo for VSCode (v0.3.10 finding)
- **SendInput virtual keys (Ctrl+V)**: `inserted=0` in VSCode — Chromium rejects synthetic keyboard shortcuts.
- **Enigo Unicode chars (direct mode)**: **WORKS** as admin — Chromium accepts Unicode character input (looks like IME).
- **UIPI**: blocks Enigo in non-admin mode. Admin mode bypasses it.
- **Conclusion for VSCode**: use **Direct mode + admin**. Or **Copy Only + manual Ctrl+V** if non-admin.

### 5.3 Injection degradation (v0.3.10 Commit 3)
Injection failure ≠ job failure. If auto-injection fails but image was uploaded:
1. Copy path to clipboard (fallback).
2. Set job state to `ReadyToPaste` (NOT `Failed`).
3. Log "Reference copied to clipboard. Press Ctrl+V."
Only mark `Failed` if BOTH injection AND copy fallback fail.

### 5.4 Clipboard-preserving (for WeChat/QQ/Feishu)
- Direct mode: never touches clipboard → original image stays → Ctrl+V into WeChat works.
- Swap mode: backs up + restores clipboard after paste.
- Copy mode: replaces clipboard with path text (image lost — paste to WeChat before Alt+V/F8).

## 7. Known Issues / Limitations

1. **VSCode auto-paste**: SendInput (virtual-key Ctrl+V) is blocked by Chromium. Workaround: Direct mode (Unicode, as admin) or Copy Only (manual Ctrl+V).
2. **Linux screenshot**: xcap PipeWire incompat — disabled (Win/Mac only).
3. **Unsigned binaries**: SmartScreen/Gatekeeper warnings.
4. **Wrap in Single Quotes**: should be OFF for Claude Code (it wants bare paths). Currently still defaults to ON.
5. **InjectionMode default**: `Auto` (spec §6.1). For VSCode users, `Direct` or `Copy` is better.
